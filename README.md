## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Mahimanagpal/portfolio-mahima.git
cd portfolio-mahima
```

### 2. Install Dependencies

For the frontend:

```bash
cd client
npm install
```

For the backend, if applicable:

```bash
cd ..
npm install
```

### 3. Environment Variables

Create a `.env` file and add the required configuration:

```env
PORT=8080
MONGO_URI=your_mongodb_connection_string
```

### 4. Run the Project

Start the backend:

```bash
npm start
```

Start the frontend:

```bash
cd client
npm start
```
